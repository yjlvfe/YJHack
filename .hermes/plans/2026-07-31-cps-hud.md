# CPS HUD Plan — AutoLeft Screen

## Summary
Add a real-time CPS counter overlay to the AutoLeft GUI screen, showing actual clicks-per-second for both AutoLeft and AutoRight. Uses the same `HudPositionEditor` widget as Tracker for positioning.

## Files to modify

| File | Change |
|------|--------|
| `autoleft/AutoLeftClient.java` | +cpsHudX, cpsHudY fields, +CpsTracker, +HudRenderCallback |
| `modgui/ModGuiClient.java` | +HudPositionEditor in AutoLeftScreen |
| `config/ConfigNormalizationTest.java` | +version bump |

## NOT touched

## Design

### CpsTracker (inner class in AutoLeftClient)
```
class CpsTracker {
    long[] clickTimestamps = new long[100];
    int writeIndex;

    void recordClick() → stores System.nanoTime()
    int currentCps() → counts timestamps within last 1 second
}
```

### HUD rendering
```
HudLayerRegistrationCallback → renderCpsHud(DrawContext, tickCounter)
  - reads AutoLeftClient.cpsHudX, AutoLeftClient.cpsHudY
  - reads AutoLeftClient.leftCps (actual), AutoRightClient.rightCps (actual)
  - draws "L:18 R:22" at config position
```

### GUI (AutoLeftScreen)
```
HudPositionEditor for CPS HUD position (after Jitter toggle)
+ cpsHudX, cpsHudY sliders (below position editor)
```

This is the complete plan. Proceed to implementation.
